# Стилі

## Будова
```
client/src/styles/
  index.css              лише @import у порядку: base → utilities
  base/tokens.css        усі кольори, відступи, радіуси, тіні, шрифт, розміри елементів
  base/z-index.css       контракт шарів
  base/reset.css         скидання браузерних стилів
  base/typography.css    базовий текст, заголовки
  utilities/a11y.css     .visually-hidden, фокус
  utilities/print.css    друк (довідка для наради)
<будь-який компонент>/X.module.css   стилі лише цього компонента
```

## Правила
- **Одна тема — світла.** Жодних `prefers-color-scheme`, жодного перемикача теми.
- **Кольори, відступи, радіуси, тіні, z-index — лише через токени** (`var(--…)`). Нове значення спершу стає токеном у `tokens.css`.
- **Кожен компонент — свій `X.module.css` поруч із `X.tsx`.** Глобальні класи — лише в `styles/base` і `styles/utilities`.
- Насичений колір — лише сигнал: червоний `--control` — контроль, `--warn` — прострочено, `--ok` — виконано. Основа — темно-синій `--brand` із золотим акцентом `--gold`.
- **Дизайн МВС (ADR-0014)**: Montserrat, значення «Токени МВС» з Figma в `tokens.css`. Офіційний знак МВС (`BrandMark`, Figma 31:1587) не перефарбовуємо й не обрізаємо, охоронна зона — ½ висоти.
- **Контраст тексту ≥ 4.5:1** на фоні, де він стоїть. Сигнальний текст — `--late-ink`, `--done-ink`, `--blue-ink`; яскраві `--late`, `--done`, `--blue` — лише заливки, рамки, значки.
- Іконки — власний набір SVG (`shared/ui/Icon`), `stroke="currentColor"`. Без емодзі.

## Шари (z-index)
Лише токени з `base/z-index.css`, ніколи число: `--z-canvas` (декоративне тло) < `--z-sticky` < `--z-nav` < `--z-header` < `--z-sheet` < `--z-popover` < `--z-toast`. Аркуші й випадні списки рендеряться порталом у `body`. Escape і клік поза шаром закривають лише верхній шар (`shared/lib/layers`).

## Жодних системних вікон браузера
- Не використовувати `<select>`, `<input type="date|time|datetime-local">` і атрибут `title`: їхні вікна малює браузер, і вони не в стилі системи.
- Короткий вибір (до ~5 варіантів) — капсули `Chips` або `Segmented`; довгий — `Picker` (на телефоні аркуш, ширше — вікно під полем, пошук через `searchable`); люди — `PeoplePicker` (до пошуку лише підказки, не весь список); дата й час — `DateTimePicker` (час за Києвом); підказка при наведенні — `data-tip="…"`.
- Прихований елемент, що сягає за край вікна (підказка, декор), — `display: none` або в межах вікна: `opacity: 0` лишає його в розмітці, і сторінка отримує горизонтальну прокрутку.
- Групу кнопок підписувати `FieldGroup`, не `Field`: `<label>` навколо кількох кнопок «натискає» першу при кліку на підпис.
- Аркуш поверх іншого аркуша — `<Sheet solid>`, інакше нижній проступає крізь скло.
- Перевірка, що системних вікон немає (порожній вивід = добре; ловить `<select>`, нативні поля дати й `title` на HTML-тегах, але не проп `title` компонентів):
  `grep -rnE "<select|type=\"(date|time|datetime-local)\"|<[a-z][a-z0-9]*( [^>]*)? title=" client/src --include=*.tsx`

## Мобільна версія
- Класи вікна (ADR-0014, `useWindowClass`): **xs** < 340 або висота < 480 · **sm** < 680 · **md** < 1200 (список і картка поруч) · **lg**. CSS-брейкпоінти — на тих самих межах (339/679/1199 px).
- `100dvh`, `env(safe-area-inset-*)` для нижньої панелі, аркушів і кнопки «+».
- Цілі для дотику ≥ 44px. Перевірка на 320×350, 344, 390, 750, 1280, 1440, 1920 — без горизонтальної прокрутки сторінки, з емуляцією дотику для телефонних розмірів.

## Доступність
Контраст AA; `:focus-visible`; `aria-label` для кнопок-іконок; `role="dialog"` + Escape для аркушів, фокус не виходить з відкритого аркуша (`Sheet` тримає його сам); стани «порожньо / завантаження / помилка» на кожному екрані.
