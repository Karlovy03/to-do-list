# Ідеї (не реалізуються в поточних задачах)

Сюди записуємо те, що помітили під час роботи. Реалізація — окремою задачею після погодження.

1. Вхід за біометрією в мобільних застосунках (Face ID / відбиток) — також зменшує ризик Apple Guideline 4.2.
2. Офлайн-перегляд останнього списку завдань у застосунку.
3. Режим push «лише номер завдання» як налаштування адміністратора (ADR-0005 залишає для цього одну точку зміни).
4. Скоупінг за підрозділами, якщо систему використовуватимуть кілька підрозділів (замінить ADR-0003).
5. Повторювані завдання (щотижневі звіти тощо).
6. Курсорна пагінація, якщо завдань стане тисячі.
7. Сповіщення з кнопками дій «Виконано» і «Відкласти» (не більше двох), відкриття одразу на завданні; повторне нагадування по тому самому завданню оновлює наявне сповіщення (той самий tag), а не додає нове. Походить з дизайну v2 у Figma.
8. Перемикач «Без прозорості» в налаштуваннях і автоматичний режим для слабких пристроїв (`navigator.deviceMemory ≤ 4`): `prefers-reduced-transparency` не працює в Android WebView та iOS WKWebView.
9. Адаптивність під розкладні: клас «середній» 680–1199 px (внутрішній екран Fold) — список і картка поруч; книжкова поза через Viewport Segments API як поступове покращення; у Capacitor 7 додати `density` до `configChanges` MainActivity, інакше застосунок перезапускається при складанні/розкладанні.
10. Пошта як запасний канал (ADR-0010 її відклав): лише важливе — нове завдання, контроль, прострочення, ранкове зведення; черга листів у БД з повторами; облік добового ліміту Gmail.
11. ntfy (власний сервер) як надійний канал для Android, якщо web push на якихось телефонах не доходитиме.
