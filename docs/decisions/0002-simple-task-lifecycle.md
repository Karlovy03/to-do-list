# ADR-0002: Простий життєвий цикл — «Виконано» без доповіді

- Статус: прийнято (рішення власника) · 2026-11-25

## Контекст
Була схема з проміжним станом «На прийнятті» і окремим «контрольним терміном доповіді». Власник: письмових доповідей не треба — людина позначає «Виконано», а за потреби керівник розпитає сам.

## Рішення
- Стани: `NEW → IN_PROGRESS → DONE` (+ `CANCELLED`). Стан `REVIEW` і поле `controlDeadline` прибрано.
- «Виконано» ставить кожен виконавець за себе; завдання `DONE`, коли позначили всі.
- Автор/керівник/контролер може «Повернути в роботу» — лише з коментарем.
- Автор/керівник може закрити достроково — лише з коментарем (йде в журнал).
- Хід виконання (відсоток, нотатка) — необов'язковий.

## Наслідки
Менше кроків для виконавця. Контроль якості — через повернення з коментарем і push автору про кожне «Виконано».
