# ADR-0004: Рушій нагадувань

- Статус: прийнято · 2026-11-25

## Рішення
- Раз на хвилину `reminders/runner.ts` під `pg_try_advisory_lock` (один прохід одночасно на всі процеси) завантажує відкриті завдання і передає їх у чисту функцію `reminders/plan.ts`.
- План повертає список «кому, що, які ключі журналу позначити». Runner спершу записує `ReminderLog`, потім надсилає (збій push не дає повторів щохвилини).
- Інтервал по контролю: завдання → людина → загальний. Пороги терміну — від `deadlineSetAt`. Тихі години й вихідні відкладають, але не гублять нагадування; термінові їх ігнорують (налаштування).
- Відкладення — `Snooze` на пару (завдання, людина).

## Наслідки
Уся логіка часу тестується без бази (`plan.spec.ts`). Масштабування на кілька процесів не дає дублікатів.
