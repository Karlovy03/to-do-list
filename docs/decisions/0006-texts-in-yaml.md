# ADR-0006: Тексти в YAML у теках модулів

- Статус: прийнято (вимога власника) · 2026-11-25

## Рішення
- Мова — лише українська, шару перекладу немає; але жоден текст не живе в коді.
- Тексти — `modules/<м>/texts/<група>.yml` (кілька файлів за змістом), спільні — `shared/texts/`, оболонки — `app/texts/`. Ключ `<м>.<група>.<ключ>`.
- Сервер повертає коди помилок; людський текст для коду — на клієнті в YAML.
- Ворота `npm run check:texts` забороняють кирилицю в коді поза коментарями й тестами.
