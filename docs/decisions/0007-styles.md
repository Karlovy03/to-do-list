# ADR-0007: Стилі — токени + CSS Modules, одна світла тема

- Статус: прийнято (вимога власника) · 2026-11-25

## Рішення
- Глобально лише `styles/base` (токени, reset, типографіка, z-index) і `styles/utilities` (a11y, друк).
- Кожен компонент — свій `X.module.css` поруч (вбудовано у Vite, без нових залежностей; Tailwind не беремо — інша модель і зайва залежність).
- Одна світла тема. Кольори МВС — тимчасові значення токенів до отримання брендбуку; герб без дозволу не використовується.
