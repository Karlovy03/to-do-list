# ADR-0008: Нативний push напряму в APNs і FCM

- Статус: прийнято · 2026-11-25

## Рішення
- iOS: офіційний `@capacitor/push-notifications` дає APNs-токен; сервер шле напряму в APNs (HTTP/2, JWT ES256 з ключа .p8). Firebase SDK в iOS-застосунок не додаємо.
- Android: FCM HTTP v1 із сервісним акаунтом; OAuth-токен кешується одним спільним запитом.
- Web: Web Push (VAPID).
- Обґрунтування: менше сторонніх SDK у застосунках, один сервер контролює всі канали, ключі — лише на сервері.
