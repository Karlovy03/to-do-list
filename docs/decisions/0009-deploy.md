# ADR-0009: Деплой — один образ, міграція до перемикання

- Статус: прийнято · 2026-11-25

## Рішення
- Один Docker-образ: сервер віддає зібраний веб-клієнт. Caddy — єдиний публічний вхід (HTTPS).
- Порядок: `build` → `migrate deploy` (на новому образі, поки старий працює) → `up -d`. Збій на будь-якому кроці лишає стару версію.
- Сервер **не мігрує базу під час старту**. Деструктивні зміни схеми — у два деплої (expand/contract).
- Часовий пояс контейнерів — Europe/Kyiv. Секрети — лише в `.env` на сервері.
